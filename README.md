# Price List Biznet Metronet

## Deploy ke Vercel

1. Upload **seluruh folder** ini (bukan hanya satu file).
2. Pastikan ada file **`index.html`** di root folder.
3. Di Vercel Dashboard:
   - **Framework Preset:** Other
   - **Build Command:** kosongkan
   - **Output Directory:** `.` (titik / root)
   - **Install Command:** kosongkan
4. Deploy ulang.

URL utama: `https://nama-project.vercel.app/`  
Halaman pengaturan: `https://nama-project.vercel.app/#pengaturan`

Jika masih kosong, buka `https://nama-project.vercel.app/index.html` — kalau ini muncul, berarti deploy benar tetapi root belum mengarah ke index.
